# Alien Hunter AR 🛸

Un joc AR (Augmented Reality) jucat direct în browser! Vânează extratereștrii care invadează camera ta.

## Cum să îl pui pe internet (GitHub Pages)

### Pasul 1: Creează un Repository nou pe GitHub

1. Intră pe [GitHub.com](https://github.com) și loghează-te.
2. Apasă pe **New Repository**.
3. Pune-i un nume (de exemplu `alien-hunter-ar`).
4. Lasă-l **Public**.
5. **NU** bifa "Initialize with README" sau altele.
6. Apasă **Create repository**.

### Pasul 2: Urcă codul

Deschide terminalul în folderul acestui proiect și scrie comenzile pe care ți le dă GitHub (sau copiază-le de aici):

```bash
git remote add origin https://github.com/USERNAME-UL-TAU/alien-hunter-ar.git
git branch -M main
git push -u origin main
```

*(Înlocuiește `USERNAME-UL-TAU` cu utilizatorul tău)*

### Pasul 3: Activează Site-ul

1. Du-te la **Settings** (în repository-ul tău pe GitHub).
2. În stânga, dă click pe **Pages**.
3. La **Build and deployment**, selectează **GitHub Actions**.
4. Gata! În câteva minute, vei primi linkul tău (ex: `https://username.github.io/alien-hunter-ar/`).

## Instalare ca Aplicație (PWA)

Pe telefon (Android/iOS):

1. Deschide linkul în Chrome/Safari.
2. Apasă pe **Share** (iOS) sau **Menu** (Android).
3. Alege **Add to Home Screen**.
4. Acum ai jocul ca o aplicație adevărată!
